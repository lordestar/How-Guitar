# 多调音方式支持 Spec

## Why

当前调音器仅支持标准调弦（EADGBE），无法满足吉他手对特殊调弦（如 DADGAD、Drop D、Open G 等）的调音需求。这些调弦在指弹、民谣、摇滚中广泛使用。本功能复用现有音高检测引擎(pitch.js)，通过切换目标调音频率，让用户无需额外工具即可完成任意调弦，同时支持自定义调弦方案。

## What Changes

- 调音器页面右下角增加"调音方式"按钮（⚙️ 图标）
- 点击后从底部弹出调音方式选择面板（Bottom Sheet）
- 面板内展示预设调音列表：标准调弦、Drop D、DADGAD、Open D、Open G、Half Step Down、Full Step Down
- 选中一个调音后面板关闭，调音器所有目标频率/弦名切换为新调音
- 面板底部有 "+ 自定义" 按钮，打开自定义调弦页面
- 自定义调弦页面：6根弦各自一个滑动选择器，限制在合理音高范围内，防止琴弦断裂
- 自定义调弦可保存命名，存入本地存储
- 删除自定义调弦：长按或滑动删除

## Impact

- Affected code:
  - `utils/pitch.js` — 不再导出硬编码 STANDARD_TUNING，改为导出调音预设列表 + 获取函数
  - `utils/tuningPresets.js` — **新增**，定义所有调音预设数据
  - `pages/tuner/tuner.js` — 增加调音切换逻辑、底部面板状态管理
  - `pages/tuner/tuner.wxml` — 增加调音切换按钮 + 底部选择面板 UI
  - `pages/tuner/tuner.wxss` — 新增底部面板样式
  - 新增 `pages/tuner/custom-tuning/custom-tuning` — 自定义调弦页面

## ADDED Requirements

### Requirement: 调音预设列表
The system SHALL provide a list of built-in tuning presets.

#### Scenario: 选择预设调音
- **WHEN** 用户点击调音器页面的"调音方式"按钮
- **THEN** 从底部弹出调音选择面板，展示所有预设调音名称

#### Scenario: 切换调音
- **WHEN** 用户点击某个预设调音
- **THEN** 面板关闭，调音器重置，6根弦的目标频率/音名切换为所选调音

### Requirement: 自定义调弦
The system SHALL allow users to create and save custom tunings.

#### Scenario: 创建自定义调弦
- **WHEN** 用户在调音选择面板点击 "+ 自定义"
- **THEN** 跳转到自定义调弦页面

#### Scenario: 设置某弦音高
- **WHEN** 用户在自定义页面拖动某弦的选择器
- **THEN** 实时显示该弦的目标音名和频率

#### Scenario: 保存自定义调弦
- **WHEN** 用户设置完所有弦的音高并点击保存
- **THEN** 校验所有音高在安全范围内，保存到本地存储，返回到调音选择面板，新调音出现在列表中

#### Scenario: 弦音安全范围验证
- **WHEN** 用户设置的某弦音高超出安全范围
- **THEN** 显示红色警告提示，阻止保存，指出具体哪根弦越界

### Requirement: 删除自定义调弦
The system SHALL allow users to delete saved custom tunings.

#### Scenario: 删除操作
- **WHEN** 用户在调音选择面板长按某个自定义调音
- **THEN** 显示删除确认弹窗
- **WHEN** 用户确认删除
- **THEN** 从本地存储中移除该调音，列表刷新

## MODIFIED Requirements

### Requirement: 调音器核心逻辑
修改 `pages/tuner/tuner.js`：

- 数据属性 `tuningOrder` 不再固定为 `pitch.STANDARD_TUNING`，而是根据当前选中的调音动态设置
- 增加 `currentTuning` 属性，存储当前调音名称
- `onLoad` 时从本地存储读取上次使用的调音，默认标准调弦
- 切换调音后调用 `resetState(0)` 重置所有调音状态
- `drawGauge` 中显示的弦名和频率跟随当前调音
- 完成弹窗文案增加调音名称（如"标准调音全部调准！"）

### Requirement: 音高检测引擎
修改 `utils/pitch.js`：

- `STANDARD_TUNING` 改为从预设数据动态获取，而非硬编码
- 保留 `detectPitch`、`freqToNote`、`calcCents` 等核心函数不变（这些与调音预设解耦）
- 谐波校正逻辑（第159-182行）当前硬编码关联 STANDARD_TUNING，改为传入当前目标频率列表

## REMOVED Requirements

无

## 弦音安全范围规范

为防止调弦时琴弦断裂，每根弦的音高范围限制如下（基于大部分民谣吉他/电吉他的标准弦张力）：

| 弦 (标准音) | 最低音 | 最高音 | 说明 |
|------------|--------|--------|------|
| 6 (E2) | B1 (61.74 Hz) | G2 (98.00 Hz) | 降4半音 ~ 升3半音 |
| 5 (A2) | E2 (82.41 Hz) | C3 (130.81 Hz) | 降5半音 ~ 升3半音 |
| 4 (D3) | A2 (110.00 Hz) | Eb3 (155.56 Hz) | 降5半音 ~ 升1半音 |
| 3 (G3) | E3 (164.81 Hz) | A3 (220.00 Hz) | 降3半音 ~ 升2半音 |
| 2 (B3) | G#3 (207.65 Hz) | C#4 (277.18 Hz) | 降2半音 ~ 升2半音 |
| 1 (E4) | C#4 (277.18 Hz) | F#4 (369.99 Hz) | 降3半音 ~ 升2半音 |

自定义调弦时，任何一根弦的音高超出此范围则提示警告并阻止保存。
