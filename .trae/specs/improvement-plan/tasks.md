## 阶段二：新功能开发（复用核心能力）

- [ ] Task 4: 音阶模式
  - 在 `utils` 中新增 `scaleDatabase.js`，定义音阶类型及音程（大调 [0,2,4,5,7,9,11]、自然小调 [0,2,3,5,7,8,10]、五声音阶 [0,2,4,7,9]、布鲁斯音阶 [0,3,5,6,7,10] 等）
  - 修改 `pages/chord/chord.js`，增加"和弦/音阶"切换开关
  - 音阶模式下，根音选择不变，类型选择替换为音阶类型
  - 修改 `utils/fretboard.js` 增加 `getScalePositions(root, scaleType)`，搜索指板上所有音阶音位置
  - 修改 `utils/draw.js` 支持两种渲染模式：
    - 和弦模式：现有圆点渲染
    - 音阶模式：所有音阶音以绿色/蓝色圆点高亮，根音红色加粗
  - 修改 `components/fretboard-viewer` 支持音阶数据传入
  - 验证：选择"C 大调音阶"，指板图显示从开放到12品的所有C大调音阶音

- [ ] Task 5: 变调夹功能
  - 在 `pages/result/result.js` 增加变调夹设置器（滑块或 +/- 按钮，0-12品）
  - 设置变调夹后：重新计算各弦实际音高，指板图上标注变调夹位置（灰色三角标记），按法圆点位置不变但音名标注上移
  - 复用 `fretboard.js` 中 `getNoteAtFret` 计算音高
  - 验证：设变调夹在2品，C和弦指法图显示实际音高为D

- [ ] Task 6: 和弦进行练习模式
  - 新增页面 `pages/practice/practice`（注册到 app.json）
  - 预设和弦进行列表（数据可放在 `utils/practiceData.js`）：
    - I-IV-V (C-F-G)
    - I-V-vi-IV (C-G-Am-F) 万能和弦
    - ii-V-I (Dm-G7-C) 爵士经典
    - 卡农进行 (C-G-Am-Em-F-C-F-G)
  - 练习模式功能：
    - 显示当前进行的和弦名称及指法图
    - 自动/手动切换下一和弦
    - 节拍器（60/80/100/120 BPM）
    - 进度条显示进行位置
  - 复用：`fretboard-viewer` 组件展示指法、`audioEngine.js` 播放和弦音
  - 首页"常见和弦进行"入口跳转到此页面
  - 验证：选择 I-V-vi-IV，按顺序显示 C→G→Am→F 指法，节拍器正常工作

- [ ] Task 7: 和弦听力训练
  - 新增页面 `pages/ear-training/ear-training`（注册到 app.json）
  - 功能流程：
    1. 系统随机选择一个和弦，用 audioEngine 播放
    2. 显示 2/4/6 个和弦选项按钮（含正确答案）
    3. 用户选择，实时反馈对错
    4. 显示连续答对次数、总正确率
  - 难度级别：简单（2选1，仅大三/小三）、普通（4选1，常见和弦）、困难（6选1，所有和弦类型）
  - 复用：`audioEngine.js` 播放、`chordDatabase.js` 数据
  - 验证：播放 C 和弦，选项中包含 C，选择正确后积分增加
