# 改进方案检查清单

## 阶段一：快速改进

- [ ] Task 1: 指板图手指编号标注
  - 按法圆点上正确显示数字 1-4（食指=1, 中指=2, 无名指=3, 小指=4）
  - 暗色模式下数字清晰可见
  - 不影响原有指板图布局和功能

- [ ] Task 2: 和弦难度评级
  - 评分算法合理，涵盖横按、跨度、制音弦、品位等因素
  - 结果页展示星级图标（⭐1-5）
  - 开放和弦（如C、Am）为低星级，大横按（如Bb、F#m）为高星级

- [ ] Task 3: 首页常见和弦进行入口
  - 首页出现第三个功能卡片入口
  - 点击后正确跳转到对应页面
  - 卡片样式与现有两个入口视觉一致

## 阶段二：新功能开发

- [ ] Task 4: 音阶模式
  - 和弦选择页可切换"和弦模式"/"音阶模式"
  - 音阶类型包含：大调、自然小调、和声小调、旋律小调、大调五声音阶、小调五声音阶、布鲁斯音阶
  - 指板图正确高亮所有音阶音
  - 根音与其他音阶音颜色区分
  - 支持前5品/前12品视图

- [ ] Task 5: 变调夹功能
  - 变调夹设置器正常工作（0-12品）
  - 指板图显示变调夹位置标记
  - 按法不变但音名标注自动平移
  - 音高信息更新

- [ ] Task 6: 和弦进行练习模式
  - 预设至少4组常见和弦进行
  - 指法图正常显示
  - 节拍器功能正常（4档速度）
  - 自动/手动切换和弦
  - 进度条显示当前位置

- [ ] Task 7: 和弦听力训练
  - 音频正常播放
  - 选项随机排列
  - 对错反馈即时准确
  - 计分系统正常工作
  - 3个难度级别均可选择
